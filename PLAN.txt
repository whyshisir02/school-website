1. PROJECT OVERVIEW
-------------------
Goal: Marketing showcase site to increase visibility/SEO + Admin panel for school to self-manage content.

8. TECH STACK
-------------
Framework: Next.js 15 App Router + TypeScript + Tailwind CSS + shadcn/ui
Database: PostgreSQL (Neon/Supabase free tier) + Prisma ORM
Auth: NextAuth.js Credentials (single admin, bcrypt) - middleware protected routes
Images: Cloudinary (Recommended - free 25GB, CDN, f_auto,q_auto) OR Supabase Storage + next/image
Deployment: Vercel (Hobby free, global CDN) + Custom Domain (.com.np / .edu.np / .com)
Email: Resend / Nodemailer for contact form
SEO: next/metadata, sitemap.ts, robots.ts, Schema.org EducationalOrganization JSON-LD, OG images

Data Model (Prisma):
  Notice { id, title, slug, content (RichText), category(Exam/Holiday/Event), isPublished, publishedAt, createdAt }
  GalleryAlbum { id, title, coverImage }
  GalleryImage { id, albumId, url, publicId, caption }
  User { id, email, passwordHash, role }
  Settings { schoolName, address, phone, email, mapLink }

9. KEY FEATURES DETAIL
----------------------
Notices: Rich Text Editor (TipTap/TinyMCE) supports Nepali Unicode + PDF attachment. Public paginated list, filter by category, search, Latest Notice marquee on Home. Each notice is static page /notices/slug with ISR revalidate 3600.
Gallery: Admin drag-drop multi-upload, client-side compress, store URL in DB. Public grid + Lightbox + Albums + Pagination 20/page + lazy load.
Performance for Nepal (slow network): next/image + Cloudinary f_auto,q_auto, lazy load gallery, ISR for notices.
